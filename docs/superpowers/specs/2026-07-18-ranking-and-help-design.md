# 排行榜查询与分层帮助设计

## 背景

JMbot 已支持站内搜索、作者作品搜索、详情、封面、收藏和下载任务。当前缺少按站点热度发现漫画的入口；同时，`/jm help` 将普通命令、下载变体、任务命令和管理员命令集中在一条消息中，文本已经过长。新增排行榜后继续扩充单页帮助会进一步降低可读性。

本次改动新增站点官方排行榜查询，并把 Bot 内帮助重构为简短索引和按主题展开的详细帮助。

## 目标

- 查询站点按浏览量排序的日榜、周榜、月榜和总榜。
- 支持主分类筛选、站内综合关键词搜索，以及关键词与分类组合筛选。
- 默认以包含封面的图片卡片返回，每个 Bot 页固定展示 5 本漫画。
- 提供结果一致的纯文本模式，并在卡片失败时自动降级。
- 复用现有查询并发限制、子进程超时保护和临时文件清理机制。
- 将 `/jm 帮助` 缩短为主题索引，并为各功能提供独立帮助页。

## 非目标

- 不支持副分类。
- 不新增点赞榜、评分榜或评论榜。
- 不统计 Bot 内部下载热度。
- 不新增定时推送或排行榜订阅。
- 不修改数据库结构，也不持久化排行榜结果。

## 命令协议

### 排行榜命令

通用语法：

```text
/jm 排行 [文本] [关键词和/或类别] [榜单] [页码]
```

默认值：

- 未指定榜单时使用总榜。
- 未指定类别时使用全部分类。
- 未指定页码时使用第 1 页。
- 未指定 `文本` 时使用图片卡片。

榜单支持：

| 规范名称 | 可接受输入 | 时间范围 |
| --- | --- | --- |
| 日榜 | `日榜`、`日` | 当日 |
| 周榜 | `周榜`、`周` | 当周 |
| 月榜 | `月榜`、`月` | 当月 |
| 总榜 | `总榜`、`总` | 全部时间 |

主分类支持：

| 显示名称 | 底层分类 |
| --- | --- |
| 全部 | `0` |
| 同人 | `doujin` |
| 单本 | `single` |
| 短篇 | `short` |
| 其他 | `another` |
| 韩漫 | `hanman` |
| 美漫 | `meiman` |
| Cosplay | `doujin_cosplay` |
| 3D | `3D` |
| 英文站 | `english_site` |

英文分类名匹配忽略大小写，因此 `cosplay`、`COSPLAY`、`3d` 和 `3D` 均有效。Bot 的帮助和结果标题始终使用表中的规范显示名称。

典型命令：

```text
/jm 排行
/jm 排行 2
/jm 排行 周榜
/jm 排行 韩漫 周榜 2
/jm 排行 全彩 韩漫 月榜
/jm 排行 韩漫 全彩 月榜
/jm 排行 文本 全彩 韩漫 月榜 2
/jm 排行 类别
```

`/jm 排行 类别` 不执行查询，而是列出支持的主分类、榜单和典型示例。

### 参数解析规则

解析器按以下优先级处理 `排行` 后的参数：

1. 如果第一个参数是 `文本`，启用纯文本模式并移除该参数；其他位置的 `文本` 不作为模式标记。
2. 如果剩余参数仅为 `类别`，返回分类列表动作。
3. 识别规范榜单名和短写，最多允许一个榜单。
4. 识别分类白名单中的独立词，最多允许一个分类。
5. 识别末尾页码。单独一个纯数字参数表示总榜对应页；当存在其他内容时，末尾纯数字表示页码。
6. 将剩余的非空文本按原顺序合并为站内综合搜索关键词。
7. 应用榜单、分类、页码和视图模式的默认值。

分类词和关键词可以交换顺序。分类白名单中的独立词始终解释为分类，因此恰好等于 `韩漫`、`同人` 等分类名的关键词无法作为关键词单独搜索。这是自由顺序语法的明确取舍。

纯数字单参数始终解释为页码，因此排行榜命令不支持仅由数字组成的关键词。普通 `/jm 搜索` 命令的数字关键词行为保持不变。

重复榜单、重复分类、互相冲突的榜单、页码小于 1，以及无法完整解析的输入均返回格式提示，不猜测用户意图。

## 查询语义

排行榜统一按浏览量排序。内部使用独立的排行榜查询模型，包含：

- 榜单时间范围；
- 主分类；
- 可选关键词；
- Bot 页码；
- 总结果数和 Bot 总页数；
- 当前页的 5 条漫画结果。

查询分为两条路径：

1. 没有关键词时，调用分类排行接口，传入时间范围、主分类和浏览量排序。
2. 有关键词时，调用站内综合搜索接口，传入关键词、时间范围、主分类和浏览量排序。

两条路径都转换为统一的排行榜结果。关键词查询的语义与现有 `/jm 搜索 <关键词>` 一致，只额外应用分类、时间范围和浏览量排序。

站点源页大小与 Bot 页大小相互独立。服务层把源结果重新分页为每页 5 本，并基于总结果数计算 Bot 总页数。第 2 个 Bot 页从全局第 6 条开始，显示第 6 至 10 名。请求越界页时不自动改写页码。

## 架构与职责

### 命令解析

`parser.py` 扩展 `JmMessage`，承载排行榜动作、榜单范围、分类、关键词、页码和视图模式。解析器只做确定性语法解析，不访问网络。

### 目录查询

`catalog_service.py` 新增独立排行榜查询模型和函数：

- 维护中文榜单、短写和底层时间参数映射；
- 维护主分类显示名、别名和底层分类参数映射；
- 根据是否存在关键词选择分类排行或站内综合搜索；
- 把 jmcomic 页面对象规范化为统一结果。

排行榜逻辑不并入现有普通搜索函数，以免普通搜索和按热度排序的语义耦合。

### 查询隔离

`query_executor.py` 为排行榜增加包装函数，继续通过现有 spawn 子进程执行元数据查询。`command_service.py` 继续使用全局查询信号量，因此排行榜查询不会阻塞 NoneBot 事件循环，也不会绕过低配服务器的查询并发限制。

排行榜查询不进入漫画下载队列。

### 编排与展示

`command_service.py` 负责执行排行榜查询、每 5 本分页、格式化成功结果，以及把异常转换为安全的用户提示。

`search_card.py` 抽取可复用的结果卡片基础布局。作者搜索和排行榜共享封面行布局，但各自提供标题、编号和命令文案。排行榜编号使用跨页连续的全局排名。

`bot.py` 负责：

- 发送现有的“收到，正在处理……”反馈；
- 调用排行榜命令服务；
- 下载当前页最多 5 张封面；
- 生成并发送卡片或发送文本结果；
- 在成功、失败和降级路径中清理全部临时文件。

## 返回内容

### 图片卡片

卡片标题回显 Bot 的实际解释，例如：

```text
韩漫 · 周榜 · 关键词：全彩
```

卡片显示当前页、总页数、总结果数，并为每项展示：

- 封面；
- 全局排名；
- JM ID；
- 标题；
- 最多 6 个标签。

卡片发送后补发可复制命令：

```text
JM123456 下载：/jm 123456
JM234567 下载：/jm 234567
下一页：/jm 排行 全彩 韩漫 周榜 2
```

下一页命令完整保留视图模式、关键词、分类和榜单，并使用规范的完整榜单名。

### 文本模式

`/jm 排行 文本 ...` 返回与卡片相同的 5 本漫画、相同的全局排名和相同的分页信息。文本模式的下一页命令保留 `文本` 标记。

## 错误与降级

- 无结果时回显实际识别出的关键词、类别和榜单，提示用户调整条件。
- 页码超过总页数时提示实际总页数，不自动跳到末页。
- 上游查询异常或超时时返回“排行榜查询暂时不可用，请稍后重试”，原始异常只写日志。
- 卡片生成失败或任一封面获取失败时，整页降级为文本结果。
- 所有卡片临时目录在成功、异常和降级后均清理。
- 无效或冲突参数返回简短语法和有效示例。

## 分层帮助

### 帮助索引

`/jm 帮助` 和 `/jm help` 返回相同的简短主题索引：

```text
JMbot 帮助：
/jm 帮助 查找  - 搜索、作者、详情、封面
/jm 帮助 排行  - 排行榜、分类和筛选
/jm 帮助 下载  - PDF、ZIP、章节、预览
/jm 帮助 收藏  - 收藏管理
/jm 帮助 任务  - 进度、队列、撤回、历史
/jmg 帮助      - 管理员命令
```

### 主题帮助

支持：

```text
/jm 帮助 查找
/jm 帮助 排行
/jm 帮助 下载
/jm 帮助 收藏
/jm 帮助 任务
/jmg 帮助
/jmg help
```

每个主题不超过 10 个非空文本行，只展示相关命令和关键说明。`/jm 帮助 排行` 包含完整语法、默认值和组合示例；具体分类列表仍由 `/jm 排行 类别` 返回。

普通帮助不再展示管理员命令详情。`/jmg 帮助` 和 `/jmg help` 只对超级管理员可用。未知帮助主题返回有效主题列表。

README 保留完整命令文档，Bot 内帮助只承担命令发现和日常用法提示。

## 测试策略

### 解析器

- 默认总榜、全部分类、第 1 页和图片模式。
- 日、周、月、总的完整名称和短写。
- 英文分类大小写别名。
- 关键词、类别以及两者的两种顺序。
- 固定位置的 `文本` 模式。
- 单独页码和带筛选条件的末尾页码。
- 分类列表动作。
- 重复榜单、重复分类、冲突参数和非法页码。
- 普通帮助主题和管理员帮助别名。

### 目录服务与查询隔离

- 无关键词时调用分类排行接口。
- 有关键词时调用站内综合搜索接口。
- 所有榜单均映射为浏览量排序和正确时间范围。
- 主分类映射正确，未指定时使用全部分类。
- jmcomic 页面对象正确规范化。
- 排行查询使用子进程超时包装。

### 命令服务与展示

- 每页固定 5 本、总页数计算和跨页连续排名。
- 下一页命令完整保留筛选条件和视图模式。
- 分类列表、无结果、越界页和安全错误提示。
- 卡片标题、封面、JM ID、标签和全局排名。
- 封面或卡片失败时发送文本结果。
- 临时目录在所有路径中清理。

### Bot 编排

- 群聊和私聊均可发送排行榜卡片与文本。
- 排行榜使用查询并发限制，不进入下载队列。
- 查询开始反馈、成功发送和失败降级行为正确。
- 普通帮助不包含管理员详情，管理员帮助受超级管理员校验。
